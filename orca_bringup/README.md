## Launch files

### [sim.launch.py](launch/sim.launch.py)

Launch a Gazebo simulation.
Calls [bringup.launch.py](launch/bringup.launch.py).

To see parameters: `ros2 launch --show-args orca_bringup sim.launch.py`

### [hw.launch.py](launch/hw.launch.py)

Launch the nodes required to connect to the hardware.
Calls [bringup.launch.py](launch/bringup.launch.py).

To see parameters: `ros2 launch --show-args orca_bringup hw.launch.py`

### [bringup.launch.py](launch/bringup.launch.py)

Launch the core nodes, including orb_slam3_ros.

### [sim_heavy.launch.py](launch/sim_heavy.launch.py)

Launch the BlueROV2 heavy simulation: Gazebo, ArduSub, mavros and RViz.
The world is the inpetu pool unless another one is given with `world:=`:

| World | Description |
| --- | --- |
| `inpetu_heavy.world` (default) | Inpetu pool |
| `corredor_heavy.world` | Corridor of 36 x 3 m with landmarks, longer than the Rolling Bonxai memory window |
| `labirinto_heavy.world` | Maze of 100 x 100 m, without landmarks; finish marked with chequered squares, way there in [solution.png](models/labirinto/solution.png) |

Example: `ros2 launch orca_bringup sim_heavy.launch.py world:=labirinto_heavy.world`

The corridor and the maze are generated by [generate_corridor.py](scripts/generate_corridor.py) and
[generate_maze.py](scripts/generate_maze.py); edit and run the scripts instead of the models.

To see parameters: `ros2 launch --show-args orca_bringup sim_heavy.launch.py`
